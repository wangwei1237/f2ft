# 面对面翻译 · Android 产品需求文档

**V1.0 评审稿　｜　目标场景：旅行中的短对话　｜　使用者：一名中文旅行者与一名英语交谈者**

在车站问路时，旅行者把手机放在两人之间，点开始后说中文。手机把问题用英文读给工作人员听，再提示对方用英语回答。双方用同一台手机确认站台、时间或目的地。对方无需安装应用、注册或学习中文界面。

## 交付范围

首版支持中文（普通话）与英语、联网翻译、手机麦克风与扬声器、前台会话。手机主人默认说中文，可交换双方语言并记住选择。耳机不是使用前提。离线语音包、更多语言、耳机独立分路及同时处理两人重叠讲话留待后续版本。原型采用固定车站对话演示状态变化。

## 页面与操作

| 页面 | 用户动作 | 系统响应 |
|---|---|---|
| 开始页 | 核对双方语言；选「开始对话」或「让对方先说」 | 记录首位发言者；首次语音使用说明联网处理并请求麦克风权限 |
| 会话页 | 看当前侧提示并讲话 | 只按当前侧语言识别；讲话时显示临时原文，停顿成句后提交翻译 |
| 会话页 | 听译文，看双语记录 | 用目标语言播报；播完自动轮到接收方，屏幕同步显示其语言提示 |
| 会话页 | 点任一侧语言按钮 | 立即切到该侧；打断播报，取消未完成的识别或翻译，已完成记录保留 |
| 会话页 | 切换面对面 | 将对方的字幕、轮次提示和按钮整体转动 180°；自己的区域保持正向 |
| 手动模式 | 按住自己一侧的说话键，松手提交 | 按下才收音，释放即结束；播完回到等待按住，不自动录音 |
| 键盘输入 | 选择发言侧、输入、发送 | 暂停收音；非空文字进入同一翻译与播报流程；取消则回到原轮次 |
| 记录详情 | 点译文放大，或点重播 | 显示整句便于当面对照；重播暂时关闭收音，结束后恢复原轮次 |
| 结束 | 点结束并确认 | 停止采集、播报及待处理请求，清除本次内容，返回开始页；取消则恢复原轮次 |

## 对话规则

1. 自动模式从选定侧开始。开放收音时显示「请说中文」或“Your turn · Speak English”；通过文字和活动指示同时传达状态。双方操作入口使用各自语言。
2. 检测到有效讲话及句尾停顿后固定原文，显示「正在翻译」。译文到达后先显示文字，再播放声音。翻译必须保留数字、否定、时间、单位和专名；不回答用户话语中的问题。
3. 播报及重播期间关闭收音。正常播报完成才自动交棒；重播不消耗轮次。由用户点击接话中断的旧请求，其迟到结果不能覆盖新轮次。
4. 输入过短、未检测到声音或识别失败时，同侧显示「没听清，请再说一次」或“Please try again”；允许重说、按住说或打字。安静等待本身不产生空消息。
5. 翻译断网时保留原文与已有记录，暂停自动收音；重试复用同条原文，避免重复消息。合成或播报失败仍展示译文，提供重播或让对方接话。
6. 拒绝录音权限后保留打字路径及重新授权入口。来电、锁屏或切后台时停止采集与播报；返回后由用户主动继续。界面显示语音联网处理提示；默认不在设备持久化原始录音和对话记录。云服务留存策略须在选定供应商后核实并告知用户。

## 发布验收

| 场景 | 操作与通过条件 |
|---|---|
| 初次问路 | 英语参与者只查看英文一侧；启动后从问站台到确认站台，连续三轮问答（六次发言），无须触屏交棒 |
| 数字与方向 | 测试集包含「四号站台，不是十四号」及 “at four fifteen”；双方能从字幕确认数字、否定与时间，放大后可返回同轮次 |
| 对方连续补充 | 正在播放时点 Speak English，旧播报停止，仅提交新发言一次；手机自己的播报不生成记录 |
| 嘈杂、拒权 | 在噪音下切换按住说话，松手后只翻译一次；首次拒绝权限后可用键盘完成双向问答 |
| 弱网与中断 | 翻译中断网、恢复后重试，原文保留且只出现一条译文；切后台后麦克风停止，返回等待继续 |
| 布局 | 面对面时隔桌读懂英文提示并能直接接话；长句可滚动，按钮有文字标签，触控区域设计至少 48 dp |
| 等待时间 | 从说话人最后一个音节到译文首个可听音节计时。建议试点目标：稳定网络下短句 P50 ≤ 2 秒、P95 ≤ 4 秒；两方向各测至少 50 句，记录设备、网络及失败数，弱网另报 |

上述耗时为拟定验收目标。句尾停顿阈值需用真实问路语料调节，重点检查说话人停顿思考时是否被提前截断。上线前先用两位参与者验证交棒可理解性，再用目标 Android 设备验证拾音、外放回录及端到端延迟。
